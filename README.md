# MerchantXporter Catalogue Hub

Public catalogue website hosted with GitHub Pages. Includes six PDF catalogues and the original MerchantXporter design, images and fonts.

## Hosting

GitHub Pages serves the `main` branch from `/ (root)`. No build, backend or secret is required.

## Catalogue updates

Replace catalogue PDF files while retaining filenames to update downloads. Update `index.html` for catalogue descriptions and links, and `styles.css` for appearance. All website assets use relative URLs to work under the repository URL.
